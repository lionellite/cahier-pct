Activation en 3 étapes

Tester avec Gemini gratuitement

Gemini 3.8 Flash est disponible avec un quota gratuit pour les projets éligibles. La clé API reste sur votre serveur : elle n’est jamais intégrée au navigateur.

  1. Créez une clé API dans Google AI Studio (connectez-vous avec votre compte Google).
  2. Dans le terminal de votre projet, copiez .env.example vers .env, puis renseignez GEMINI_API_KEY.
  3. Redémarrez Flask. Le statut en haut à droite indiquera que l’assistant est prêt.

Important : sur le quota gratuit, Google peut utiliser les entrées et réponses pour améliorer ses produits, et des évaluateurs humains peuvent les examiner. Ne transmettez aucun renseignement personnel, sensible ou confidentiel.
